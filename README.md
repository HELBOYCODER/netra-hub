# ⚡ NETRA HUB — Serverless VPN Proxy, Sales Panel & Telegram Bot

سیستم یکپارچه مدیریت فروش کانفیگ و پروکسی‌های VLESS/Trojan بر بستر Cloudflare Workers و D1 Database به همراه پنل تحت وب شیشه‌ای و ربات تلگرام فول‌کنترل.

---

## 🌟 امکانات اصلی (Key Features)

1. **موتور سرور زئوس (Zeus Core Engine):**
   - اتصال به بیش از ۴۴,۰۰۰ آیپی تمیز اپراتورهای ایران (همراه اول، ایرانسل، رایتل، مخابرات، شاتل، آسیاتک)
   - تولید خودکار ۲۵ تا ۳۰ گره آیپی تمیز و پایدار در هر لینک سابسکریپشن
   - پشتیبانی از پروتکل‌های VLESS-WS (TLS & Non-TLS)، Trojan-WS و فرگمنت پیشرفته (`tlshello, 100-200, 1-1`)

2. **ربات مدیریت و فروش تلگرام (@netranew_bot):**
   - **ساخت مرحله‌ای ۳ گام:** دریافت نام -> دریافت حجم -> تعیین مدت انقضا
   - **پشتیبانی آنی از اکانت‌های آن‌لیمیتد (نامحدود):** ساخت تک‌کلیک بدون نیاز به ورود روز + درج تگ `(♾️ آن‌لیمیتد)` روی تمام گره‌ها
   - **تولید و ارسال مستقیم عکس QR Code:** ارسال تصویر QR سابسکریپشن برای اسکن آنی با v2rayNG / Sing-box
   - **مدیریت کامل کاربران به صورت شیشه‌ای:**
     - مشاهده کارت مشخصات، مانده حجم و روزهای اعتبار
     - مسدود / فعال‌سازی آنی کاربر
     - صفر کردن ترافیک مصرفی (`used_gb = 0`)
     - تغییر سقف حجم (GB) و تعداد روزهای اعتبار با دکمه‌های آماده یا عدد دلخواه
     - حذف کامل کاربر از دیتابیس همراه با تاییدیه دو مرحله‌ای
     - لیست کاربران همراه با صفحه‌بندی (Pagination)
     - دستورات سریع: `/add`, `/del`, `/block`, `/unblock`, `/reset`, `/edit`, `/info`, `/users`, `/stats`, `/sub`, `/status`, `/web`

3. **وب‌پنل اختصاصی (Luxury Dark Glass UI):**
   - طراحی مطابق استاندارد Taste Redesign (تیره، فونت وزیرمتن، المان‌های مات، اعداد جدولی)
   - کارت‌های آماری مجموع کاربران، کاربران فعال و کل ترافیک مصرفی
   - جدول مدیریت لحظه‌ای با امکان ویرایش، تغییر وضعیت، حذف و کپی لینک ساب و QR

## 📁 ساختار پروژه

```
├── worker.js          # سورس کامل کلودفلر ورکر (موتور پروکسی، ربات تلگرام، وب‌پنل، سابسکریپشن)
├── schema.sql         # ساختار کامل دیتابیس D1 (جداول users, settings)
├── wrangler.toml      # کانفیگ دیپلوی روی Cloudflare Workers
└── README.md          # مستندات کامل پروژه
```

## 🚀 نحوه راه‌اندازی و دیپلوی مجدد

### ۱. ساخت دیتابیس D1 در Cloudflare
```bash
npx wrangler d1 create ersaz_panel_db
# سپس شناسه دیتابیس را در wrangler.toml قرار دهید
npx wrangler d1 execute ersaz_panel_db --file=./schema.sql
```

### ۲. دیپلوی ورکر
```bash
npx wrangler deploy
```

### ۳. فعال‌سازی وب‌هوک ربات تلگرام
```bash
curl -s "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=https://<YOUR_WORKER_DOMAIN>/telegram"
```
